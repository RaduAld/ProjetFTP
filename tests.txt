===============================================================================
  SERVEUR FTP — GUIDE DE TESTS MANUEL
===============================================================================

STRUCTURE DES FICHIERS FOURNIS
-------------------------------
Placer les fichiers ci-joints comme suit AVANT de lancer le serveur :

    repServeur/hello.txt    ← copier hello.txt ici
    repServeur/large.txt    ← copier large.txt ici
    repClient/upload.txt    ← copier upload.txt ici

Ces répertoires sont créés manuellement une seule fois :

    mkdir -p repServeur repClient

À chaque ./server, les esclaves copient le contenu de repServeur/ dans leur
répertoire propre (repServeur0/, repServeur1/, ...) via cp -rf. Les tests
vérifient sur ces répertoires individuels, pas sur repServeur/ directement.

COMPILATION
-----------
    make


===============================================================================
DÉMARRAGE — garder ce terminal ouvert pendant tous les tests
===============================================================================

    ./server

Sortie attendue :

    Maître : en attente de 5 esclave(s) sur le port 2120...
    [Esclave 0] Répertoire initialisé depuis repServeur/
    [Esclave 0] Port d'écoute ouvert sur 2122, répertoire : ./repServeur0/
    ...
    Maître : tous les esclaves sont enregistrés. Prêt à accepter des clients.
    Démarrage du pool de 5 processus sur le port 2121...

--- Q1–Q3 : GET d'un petit fichier ---

    rm -f repClient/hello.txt
    ./client localhost 2121

    get hello.txt
    bye

    diff repServeur0/hello.txt repClient/hello.txt
    # Résultat attendu : aucune sortie (fichiers identiques)


--- Q4 : Arrêt propre du serveur ---

Appuyer sur Ctrl+C dans le terminal du serveur.
Vérifier qu'aucun esclave ne reste actif :

    ps aux | grep esclave
    # Résultat attendu : aucun processus listé

Redémarrer le serveur avant de continuer :

    ./server


--- Q5 : Répertoires de travail distincts ---

    rm -f repClient/hello.txt
    ./client localhost 2121

    get hello.txt
    bye

    ls repClient/hello.txt
    # Résultat attendu : fichier présent dans repClient/, pas à la racine


--- Q6–Q7 : GET d'un fichier inexistant ---

--- Q8 : Transfert par blocs (grand fichier, > MAXCHAR=100 octets) ---

--- Q9 : Plusieurs requêtes par connexion ---

    rm -f repClient/hello.txt repClient/large.txt
    ./client localhost 2121

    get large.txt

    diff repServeur0/hello.txt repClient/hello.txt
    diff repServeur0/large.txt repClient/large.txt

--- Q10 : Reprise de transfert après interruption ---

Etape 1 — lancer et interrompre avec Ctrl+C avant la fin :

    ./client localhost 2121
    get large.txt
    [Ctrl+C]

Etape 2 — relancer et redemander le même fichier :

    ./client localhost 2121
    get large.txt
    bye

    diff repServeur0/large.txt repClient/large.txt
    # Résultat attendu : aucune sortie (reprise à l'offset correct)

--- Q13 : Redirection et tourniquet ---

Ouvrir deux terminaux simultanément :

Terminal A :
    ./client localhost 2121
    bye

Terminal B (lancer juste après A) :
    ./client localhost 2121
    bye

Résultat attendu : A atterrit sur le port 2122 (esclave 0),
B sur le port 2123 (esclave 1). Le terminal serveur affiche :
    [FilsXXX] Client redirigé vers esclave 0 (localhost:2122)
    [FilsXXX] Client redirigé vers esclave 1 (localhost:2123)

--- Q15 : Commande ls ---

    ./client localhost 2121

    ls
    bye

    # Résultat attendu : hello.txt et large.txt dans la liste
    # (contenu de repServeur0/ ou repServeur1/ selon le tourniquet)


--- Q16 : Commande put + propagation ---

    rm -f repServeur0/upload.txt repServeur1/upload.txt
    ./client localhost 2121

    login admin 1234
    put upload.txt
    bye

    # Vérifier la présence sur l'esclave qui a reçu le put :
    ls repServeur0/upload.txt

    # Attendre la propagation puis vérifier l'autre esclave :
    sleep 1
    ls repServeur1/upload.txt
    # Résultat attendu : fichier présent sur les deux esclaves

    # Vérifier le contenu :
    diff repClient/upload.txt repServeur0/upload.txt
    diff repClient/upload.txt repServeur1/upload.txt


--- Q16 : Commande rm + propagation ---

    ./client localhost 2121

    login admin 1234
    rm upload.txt
    bye

    # Vérifier la suppression sur l'esclave qui a reçu le rm :
    ls repServeur0/upload.txt
    # Résultat attendu : No such file or directory

    # Attendre la propagation puis vérifier l'autre esclave :
    sleep 1
    ls repServeur1/upload.txt
    # Résultat attendu : No such file or directory

    # rm d'un fichier inexistant doit retourner une erreur :
    ./client localhost 2121
    login admin 1234
    rm fichier_inexistant.txt
    bye
    # Résultat attendu : "Erreur: fichier introuvable ou suppression impossible"


--- Q17 : Authentification ---

Test 1 — put/rm sans login refusés :

    ./client localhost 2121
    put upload.txt
    bye
    # Résultat attendu : "Erreur: authentification requise"

    ./client localhost 2121
    rm hello.txt
    bye
    # Résultat attendu : "Erreur: authentification requise"

Test 2 — mauvais mot de passe :

    ./client localhost 2121
    login admin mauvais_mdp
    bye
    # Résultat attendu : "Erreur: login ou mot de passe incorrect"

Test 3 — login valide :

    ./client localhost 2121
    login admin 1234
    bye
    # Résultat attendu : "Authentification réussie"

Test 4 — état d'auth limité à la connexion courante :

    # Connexion 1 : login réussi
    ./client localhost 2121
    login admin 1234
    bye

    # Connexion 2 : sans login, put doit être refusé
    ./client localhost 2121
    put upload.txt
    bye
    # Résultat attendu : "Erreur: authentification requise"
